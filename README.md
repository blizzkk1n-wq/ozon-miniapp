# 🎣 OzonDay — Автоматический сервис мониторинга и бронирования смен в OzonJob

Автономный программный комплекс для круглосуточного отслеживания свободных слотов в приложении **OzonJob** (`ru.ozon.hire`) и автоматической записи на смены через смартфон (ADB).

---

## 📁 Структура проекта

```
OzonDay/
├── telegram_service.py     # Основной бэкенд Telegram-бота (telebot)
├── database.py             # Работа с базой данных SQLite (очередь заявок FIFO, пользователи)
├── watch_ozon.py           # Дозорный робот: мониторинг и авто-бронирование через ADB
├── adb_utils.py            # Общие функции ADB: замок между процессами, безопасные вызовы
├── telegram_config.json    # Токен бота и Telegram ID (создайте из telegram_config.example.json)
├── requirements.txt        # Python-зависимости (pyTelegramBotAPI)
├── run_bot.bat             # Скрипт быстрого запуска бота в Windows
├── run_watcher.bat         # Скрипт быстрого запуска дозорного робота в Windows
│
└── webapp/                 # Фронтенд Telegram Mini App (GitHub Pages)
    ├── index.html          # Главная страница (AMOLED дизайн, выбор складов, кнопка «Ловить»)
    ├── logo.jpg            # Фирменная 3D-иконка (крючок, солнце и луна)
    ├── terms.html          # Условия использования
    └── privacy.html        # Политика конфиденциальности
```

## ⚙️ Установка и настройка

1. **Установите Python 3.10+**:
   Убедитесь, что Python добавлен в переменную PATH.

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте Telegram-бота**. Скопируйте `telegram_config.example.json` в `telegram_config.json`
   (файл не публикуйте и не отправляйте в чаты) или задайте переменные окружения `BOT_TOKEN` и `ADMIN_ID`:
   ```json
   {
     "bot_token": "ВАШ_ТОКЕН_ОТ_BOTFATHER",
     "chat_id": "ВАШ_TELEGRAM_ID"
   }
   ```

4. **Подключение смартфона**:
   - Включите **«Отладку по USB»** на телефоне.
   - Подключите смартфон по кабелю к компьютеру.
   - Проверьте подключение командой:
     ```bash
     adb devices
     ```
   - Должно появиться устройство со статусом `device`.

5. **Запуск сервиса**:
   - Запустите бота: двойной клик по `run_bot.bat` (или `python telegram_service.py`).
   - Запустите робота-дозорного: двойной клик по `run_watcher.bat` (или `python watch_ozon.py`).

## 🌐 Публикация Web App (GitHub Pages)

Файлы из папки `webapp/` (`index.html` и `logo.jpg`) загружаются в репозиторий GitHub Pages (например, `blizzkk1n-wq/ozon-miniapp`), ссылка на который указана в `telegram_service.py` (`WEBAPP_URL`).

## 🔧 Настройки дозорного (`watch_ozon.py`, блок «Настройки»)

| Параметр | Что делает |
|---|---|
| `REQUIRE_WAREHOUSE_ON_SCREEN` | Бронировать, только если склад из заявки виден на экране приложения. Если приложение не показывает название склада — поставьте `False`. |
| `STRICT_ACCOUNT_MATCH` | `True` — обслуживать заявки только пользователя, чей номер залогинен на телефоне (`/setdevice 9XXXXXXXXX` или вход через бота). |
| `SUCCESS_MARKERS` / `FAIL_MARKERS` | Тексты на экране после «Записаться». Подберите под реальные экраны OzonJob. |
| `CHECK_INTERVAL_SECONDS` | Пауза между циклами. |

Если по экрану не удалось понять, записалась ли смена, заявка получает статус `review`, оплата **не списывается**,
администратору приходит сообщение с командами `/confirm <id>` (списать и уведомить клиента) и `/reject <id>` (вернуть в поиск).

> Ограничение архитектуры: пока ловля идёт через один телефон, на нём одновременно залогинен один аккаунт Ozon.
